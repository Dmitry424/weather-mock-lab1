## Запуск

У PowerShell у папці проєкту:

```powershell
./launch.ps1 server
./launch.ps1 tcp
./launch.ps1 udp
./launch.ps1 alerts
./launch.ps1 test
```

Кожний режим запускається в окремому терміналі. launch.ps1 використовує наявний Python із середовища Codex. На іншому комп'ютері з Python 3:

```text
python weather_mock.py server
python weather_mock.py tcp
python weather_mock.py udp --output result.json
python weather_mock.py alerts
python -m unittest -v test_weather
```

Команди TCP: `GET_WEATHER Kyiv`, `GET_WEATHER Київ`, `EXIT`. Міста з пробілами також підтримуються. Відповіді - JSON у UTF-8, один рядок на повідомлення. Максимальний кадр запиту - 4096 байтів із LF. Mock-погода стабільна для заданого імені міста.

Сервер: TCP 9000, UDP 9001, адреса 127.0.0.1. За замовчуванням відкидає Packet #10, #20, ...; для контролю: `python weather_mock.py server --drop-every 0`. Для доступу з іншого комп'ютера явно встановіть `--host 0.0.0.0`, на клієнті - IP сервера. Досліди виконані лише на loopback.

UDP alerts: SUBSCRIBE реєструє адресу слухача, кожні 2 секунди сервер надсилає EMERGENCY_ALERT кожному підписнику окремою датаграмою; UNSUBSCRIBE прибирає його, неоновлена підписка спливає за 300 с. Це розсилання unicast за списком підписок, а не IP broadcast. Для довгих сеансів слід повторно підписатися.

100 запитів Packet #N виконуються послідовно з таймаутом 1 с, ACK звіряється за джерелом і номером. Відсутність ACK вимірює прикладну втрату відповіді; відкинуті сервером запити залишаються видимими в pcapng. Локальний результат не прогнозує втрати або RTT в інтернеті.

## Докази

`evidence/traffic.pcapng` - справжнє захоплення Npcap/dumpcap (Wireshark) із фільтром `tcp port 9000 or udp port 9001`.

Фільтри перегляду: `tcp.stream == 0` (handshake кадри 1, 8, 11), `frame.number == 96` (штормове повідомлення), `udp.port == 9001`, `tcp.flags.fin == 1`.

`evidence/udp_10.json`: 100/90/10, 10%; `udp_0.json`: 100/100/0, 0%. Повні журнали, знімки вікон, тести й експорт полів пакетів збережені поруч. Знімки панелі результатів відображають записані фактичні сеанси, а не відкриті в цей момент термінали.

`run_experiment.py` повторює дослід (потрібні вільні порти та Wireshark у K:\wireshark). Він перезаписує evidence, тому оригінальні докази спочатку скопіюйте. `--viewer` показує результати. `build_report.py` створює PDF і потребує reportlab та Pillow з наявного середовища.

Публічний GitHub: https://github.com/Dmitry424/weather-mock-lab1 (гілка main). Початковий код не був опублікований перед розробкою, тому хронологію публікації зі зразка методички не заявлено.

## Живі консольні сеанси

`python live_console_demo.py` відкриває окрему консоль сервера та чотири справжні консольні клієнти для Kyiv, Lviv, Odesa, Dnipro. Клієнти залишаються підключеними 5 хвилин і кожні 10 секунд виконують запит, потім надсилають EXIT. Журнали зберігаються у `evidence/live/`. Скрипт використовується для підготовки нових скриншотів, на додачу до початкової панелі записаних результатів.
